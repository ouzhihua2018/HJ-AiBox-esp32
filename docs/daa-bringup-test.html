Si3050 + Si3019 分步测试说明

给不会模拟电路、按手册应用图抄板的人用。每一关只证明一层。前一关不过，不要插电话线，更不要摘机。

固件：idf.py menuconfig → Daa Voice Terminal → DAA_BRINGUP_GATE。默认 1。测回环改成 2。串口 115200。设为 7 才走原来的连云路径。

1. 这块板在干什么

电话线上的声音是模拟的。Si3019 在电话线那一侧（IGND），Si3050 在 ESP32 这一侧（DGND）。中间靠隔离电容传数字，不是变压器。

电话线 TIP/RING
    │
  Si3019（线路侧，IGND）
    │  隔离电容 C1/C2/C8/C9
  Si3050（系统侧，3.3V / DGND）
    │
    ├─ SPI：只配寄存器，不传语音
    └─ PCM：PCLK / PSYNC / DRX / DTX 传样点
         │
       ESP32-S3

上电复位后，手册规定：隔离链路默认关着（PDL=1），线路侧等于没接上。这时可以 SPI 读写 Si3050，也可以做芯片内部的数字回环，但读不到铃、线路电压，也不能真正摘机。这是安全默认，也是我们先测数字口的原因。

3. 硬性顺序（为什么必须这样）

RESET 拉高之前，PCLK 至少已经跑了 10 个周期。 Si3050 用 PCLK/FSYNC 锁内部 PLL。没有时钟就释放复位，后面 PCM 帧对不齐，SPI 即使读通了，语音也会是垃圾。

RESET 拉高的那一瞬，SCLK 必须为高。 芯片用这只脚在复位边沿二选一：高 = PCM 语音 + SPI 寄存器；低 = GCI（语音和控制挤在同一组线上）。我们走 PCM+SPI。一旦进了 GCI，SDI/SDO 的含义全变，后面每一关都是假失败。

FDT 没置 1，软件禁止写 OH=1。 隔离墙没通，线路侧状态无效，摘机没有意义，还有误占线风险。

Gate 0–3 不插 RJ11。 先证明 3.3V、SPI、PCM 四根线、隔离电容，再让 48V / 铃流进来。

正确上电：
  3.3V 稳定
  → ESP32 先出 PCLK + PSYNC（IO38 / IO39）
  → 把 SCLK（IO11）用 GPIO 拉高（此时还不要开 SPI 主机，SPI Mode0 空闲是低）
  → /RESET 低 ≥ 1 ms（256 kHz 时 10 个 PCLK 约 40 µs，拉 1–2 ms 更稳）
  → /RESET 拉高（锁死 PCM+SPI）
  → 再把 IO11 交给 SPI 驱动（空闲变低没关系，模式已经锁住）

4. PCM 时序对齐：Si3050 怎么配（手册 5.32 / 5.33 / Register 33–37）

手册写死三件事：FSYNC 必须 8 kHz；PCLK 只能是 256 kHz～8.192 MHz 那几档；芯片在 FSYNC 上升沿 之后数 PCLK，数到 TXS/RXS 才开始传 MSB。

ESP32 当主机出 PCLK 和 FSYNC。Si3050 当从机。PLL 会自己算出 PCLK/FSYNC 的比值，软件不用写分频。

4.2 TXS / RXS：对齐的核心

Reg34–35 = TXS[9:0]，Reg36–37 = RXS[9:0]。含义（原文）：FSYNC 上升沿之后再过多少个 PCLK，才开始传/收 MSB。写 0 表示 MSB 就在 FSYNC 上升沿那一个周期（Figure 30）。

Table 8 边沿约定（用来核对示波器，不是用来改寄存器的）：

  • DTX 在 PCLK 上升沿 更新
  • DRX 在 PCLK 下降沿 之前建立、之后保持（tsu2 / th2）
  • FSYNC 上升要在某次 PCLK 下降之前 ≥25 ns 就绪

4.3 一帧 32 bit，不是 64 bit

合法 PCLK（Table 8）：256 / 512 / 768 kHz、1.024 / 1.536 / 2.048 / 4.096 / 8.192 MHz。FSYNC 永远 8 kHz。一帧里的 PCLK 个数 = PCLK ÷ 8 kHz。

空槽本身没问题：PCM highway 就是「一帧里很多 8-bit timeslot，本芯片只用其中两个」。手册写 DTX 只在自己的 16 bit 里驱动，其余时间高阻。所以 有 空槽是设计如此。

不合适的是把 ESP32 配成 32-bit × 2 槽 = 64 bit/帧（512 kHz）。Si3050 仍然只吃前 16 bit，等于白留 48 bit。ESP-IDF 标准 Philips 永远是 2 个 slot，最低合法配法是：

ESP32 I2SPCLK一帧Si3050 用掉空槽
32-bit × 2（旧）512 kHz64 bit16 bit48 bit，过宽
16-bit × 2（现在）256 kHz32 bit16 bit16 bit，下限
16-bit × 1128 kHz16 bit16 bit0，但 Table 8 没有 128 kHz

所以空 16 bit 去不掉：再瘦就会低于 Si3050 允许的最低 PCLK。TXS=1 仍然是「上升沿后再过 1 拍」，不必随帧长改。

4.4 和 ESP32 I2S 的接线（已经写在工程里）

ESP32 I2S0 主机                 Si3050 从机
BCLK  IO38  ────────────────►  PCLK

DOUT  IO14  ────────────────►  DRX     （我们对芯片说话）
DIN   IO21  ◄────────────────  DTX     （芯片对我们说话）
bit_shift = true  ←→  TXS = RXS = 1

不要把 WS 留在 I2S 默认极性（左槽为低）。那样上升沿会落到右槽，Si3050 会采空槽，回环能量接近 0。

不要用 µ-law（PCMF=01）。那是北美压扩，样点不是 int16。

4.5 初始化顺序里 PCM 插在哪（手册 5.3）

1. 上电，RESET 拉低再拉高（PCLK 已在跑，SCLK 在上升沿为高）
2. 等 PLL：Tsettle ≈ 64/PCLK，256 kHz 时约 0.25 ms，我们等 2 ms
3. 先写 Reg34–37（TXS/RXS），再写 Reg33 打开 PCM
4. 国家参数（中国：Table 13 ACIM=1010 等）—— Gate 3 清 PDL 之前再写
5. FULL/IIRE 保持 0
6. 最后才写 Reg6=0x00 打开线路侧（Gate 3）

Gate 1 读通寄存器后，固件会立刻执行第 3 步。Gate 2 的 PDL=1 回环必须在 PCM 已使能时才能在 DTX 上看到自己发出的波形。

5. 关卡

Gate 0 — 上电，不插电话线

为什么：先确认盒子自己的 3.3V 和隔离条，排除电源和短路。此时故意把 /RESET 拉低，芯片保持手册复位态：不会自己摘机占线。

通过：串口有日志；万用表 Si3050 VDD=3.3V；DGND 与 IGND 不导通；IO4 能读到 ADC raw（分压比以后再标定）。

失败：没 3.3V → 查 Type-C / 电源芯片。两边地导通 → 查隔离电容连锡、隔离槽被铜皮连上。

Gate 1 — 复位进 PCM+SPI，读寄存器

为什么：这是整板数字侧的第一道铁证。还没打开隔离墙，也还没插电话。读到稳定、非全 0/全 1 的寄存器，才能证明：时钟进了芯片、复位边沿选对了 PCM+SPI、四根 SPI 没接反。

SPI 按手册 5.35：每笔是 Control + Address + Data（16-bit 主机一次拉 32 个 SCLK）。单芯片 CID=0：写 Control=0x20，读 Control=0x60。不是 0x80|addr 那种两字节协议。

串口应反复打印 REG6 REG11 REG12。复位后 REG6 的 PDL 位（bit4）应为 1，常见 0x10。

通过：连续 5 次读一致，且不是全 00 / 全 FF。日志出现 GATE1 PASS，随后 PCM cfg REG33=0x39 TXS=1 RXS=1。

失败分层：

  • 全 FF 或全 00：SPI 没挂上，或进了 GCI。示波器看 RESET↑ 时 IO11 是否为高；SDI/SDO 是否对调。
  • 每次乱跳：CS 时序或速率。固件已用 200 kHz，仍乱再查飞线/虚焊。
  • REG6.PDL 不是 1：读写相位（Mode0）可能不对，先别往下关。

Gate 2 — PDL=1 数字回环（仍不插电话线）

为什么：手册默认 PDL=1 时，线路侧掉电，系统侧把 DRX 收到的数字样点经片内收发滤波器送到 DTX。约 0.9 dB 衰减，有群时延。不需要 Si3019 工作，不要摘机，不要清 PDL。这一关只证明 PCM 四根线（IO38/39/14/21）和帧对齐，与电话线无关。

链路（墙是关的）：

ESP32 I2S TX
    IO14 DOUT ──► Si3050 DRX
                      │
                      │  PDL=1：内部数字回环
                      │  （发送滤波 + 接收滤波，不经过 Si3019）
                      ▼
    IO21 DIN  ◄── Si3050 DTX
ESP32 I2S RX

TIP/RING、Si3019、隔离链路上没有声音。你在串口里看到的，是自己发出去的波形晚一点、稍小一点回来。

串口应看到 LOOPBACK TX RMS=… RX RMS=…，以及 GATE2 PASS 或 FAIL。

通过：RX RMS 大约是 TX 的 0.8～1.0 倍（手册约 0.9 dB 衰减）；1 kHz 的 Goertzel 远大于 2 kHz。头几个样点应能看出正弦，不是全 0。

失败：

  • RMS 接近 0：IO14/21 交叉、PCLK/PSYNC 没出、或 REG33 PCME 没开（DTX 高阻）。
  • 有能量但 1 kHz 不明显：16-bit 窗口或 bit_shift/TXS 错 1 bit，样点被撕碎。
  • PDL 不是 1：不要在这一关写 REG6=0，那是 Gate 3。

清掉 PDL 以后，DTX 改走线路侧 ADC，这条内部回环会消失。所以 Gate 2 必须在 PDL=1 时做，不要和 Gate 3 搅在一起。

Gate 3 — 清 PDL，等到 FDT=1，确认 Si3019

为什么：PDL=Powerdown Line-side。写成 0 才打开隔离墙上的通信。FDT（Register 12 bit6）表示系统侧和线路侧已经握手成功。LSID=0011 表示对面是 Si3019。墙没通，后面铃、电压、摘机全是假的。 
写 REG6 = 0x00（PDL=0, PDN=0）
    → 等 FDT=1（一般数毫秒到几十毫秒）
    → 读线路侧识别 LSID

通过：FDT=1，LSID=0011。

失败：FDT 一直 0 → C1/C2/C8/C9、Si3019 供电/焊接、IGND。不要用「插上电话听有没有声」代替这一关。

Gate 4 — 第一次插电话线，仍挂机，读 LVS

为什么：OH 保持 0。LVS（Reg29，约 1 V/bit）看 TIP–RING 直流。空闲局端常见约几十伏。用来证明并机接到了真线，且没有把线直流短路。

通过：LVS 是几十伏量级；原座机仍能打出/打进。

失败：LVS≈0 → 没接到局端、极性/断线，或 FDT 实际没通。

Gate 5 — 振铃

为什么：铃流是线上的高压交流，并机的座机和 Si3019 同时看到，盒子不用「转发」铃声。FDT 未置位时手册写明 RGDT 不工作。人有没有接听，看 LVS 下跌，不要把铃与铃之间的静音当成「人接了」。

看 IO12（RGDT）和寄存器 RDT。原座机应同时响。

Gate 6 — 摘机 + PCM 对讲

为什么：只有 FDT=1、且 LVS 仍高（人没先摘座机）时，才写 OH=1。LCS 表示盒子自己拉通了回路。然后才用 Gate 2 已对齐的 PCM 跟对端说话。

失败分层：OH=1 但 LCS=0 → 线路侧终止/整流，不是 SPI。有电流无声 → 槽位/PCMF。只有单向 → DRX/DTX 接反。

Gate 7 — 才接 Wi-Fi / 大模型

前六关全过，再把 DAA_BRINGUP_GATE 设为 7。这关失败先查网络，不要回头怀疑模拟——除非 Gate 6 已经不稳。

7. 定位口诀

  • Gate 1 不过：焊盘 / SPI / 复位时 SCLK 不是高。
  • Gate 2 不过：PCM 四根线或 16-bit 窗口没对齐。
  • Gate 3 不过：隔离电容和 Si3019。
  • Gate 4 以后：才是电话线和模拟。

不要用「插上线听有没有声」当第一测项。
